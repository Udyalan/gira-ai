# Piñata Party

A festive, kid-friendly slot-style browser game inspired by *Pinata Wins* — **no real-money gambling**.

## Features

- 5×3 grid with simple matching logic (placeholder for full paylines)
- Cascading animations, coin & XP rewards (virtual only)
- Local progress persistence via `localStorage`
- React + Vite + TypeScript

## Getting Started

```bash
pnpm install   # or npm install / yarn install
pnpm dev       # starts Vite dev server on http://localhost:5173
```
